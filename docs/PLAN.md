# План прототипа (утверждён 2026-10-04)

Правила и допущения подробно описаны в [DECISIONS.md](DECISIONS.md), типы всех сущностей — в `src/domain/types.ts`.

## Сущности

| Сущность | Назначение |
|---|---|
| Company | Участник площадки: роль, контактные лица, данные проверки по реестру, дата последнего входа |
| RegistryRecord | Ответ адаптера реестра: статус, дата основания, отчётность |
| Listing (Cargo / Truck) | Объявление: общее ядро полей и поля груза; срок жизни, статус, «открытое», приоритет |
| ContactAccess | Доступ смотрящего к контактам размещающего, один на пару, навсегда |
| LedgerTransaction | Проводка; баланс = сумма проводок |
| ContactPackage | Пакет контактов на период |
| Review | Отзыв, возможен ответ владельца |
| Claim | Претензия (деловой спор), влияет на рейтинг |
| Complaint | Жалоба на объявление («неактуально», «не отвечает»), модерируется |
| Flag | Блокирующий флаг: красный или жёлтый |
| Subscription | Сохранённый поиск: частота «сразу» или дайджест |
| Notification | Уведомление внутри прототипа |
| RouteTemplate | Шаблон повторяющегося маршрута |
| EventLogEntry | Событие с причиной и временем, в том числе изменение рейтинга |

## Связи

- Компания владеет объявлениями, контактными лицами, проводками, подписками, шаблонами и уведомлениями.
- ContactAccess (смотрящий → владелец) — основание для отзыва, претензии и жалобы «не отвечает».
- Review, Claim и Flag ссылаются на компанию. Complaint ссылается на объявление и на его владельца.
- Возврат — отдельная проводка `refund`, ссылается на жалобу.
- Рейтинг не хранится: это чистая функция от состояния и текущей даты. Событие рейтинга — разница «до/после» при доменном действии.

## Экраны

1. Верхняя панель: «войти как», дата и сдвиг времени, баланс, уведомления, сброс.
2. Поиск: грузы и машины, фильтры, сортировка, сохранение подписки, пустые состояния.
3. Карточка объявления: блок «кто разместил», кнопка контакта, предупреждение о флаге, жалоба.
4. Профиль компании: балл, компоненты, события, отзывы, претензии, проверка, флаги.
5. Мои объявления: продление, «открытое», приоритет, снятие с причиной.
6. Размещение груза и машины, шаблоны.
7. Регистрация с проверкой по реестру.
8. Баланс и пакеты.
9. Уведомления и подписки.
10. Модератор: жалобы, претензии, флаги.
11. Лог событий.

## Этапы

Первая итерация:

- **E1.** Каркас, доменные типы, config, адаптеры с заглушками, хранилище с localStorage и сбросом, i18n, сид-данные, «войти как».
- **E2.** Сквозной сценарий: поиск груза → карточка с рейтингом → открытие контакта со списанием баланса. Расчёт рейтинга и правила контактов покрыты тестами.
- **E2.5.** README и [ROADMAP.md](ROADMAP.md) с задачами E3–E12 и критериями готовности.

Дальнейшие этапы (подробности будут в ROADMAP.md):

- **E3.** Управление временем, лог событий, пополнение баланса.
- **E4.** Полный поиск.
- **E5.** Профиль компании.
- **E6.** Размещение и «мои объявления».
- **E7.** Отзывы и претензии.
- **E8.** Жалобы, модерация, флаги.
- **E9.** Подписки и уведомления.
- **E10.** Регистрация и деактивация.
- **E11.** Пакеты контактов.
- **E12.** Мобильная адаптация и итоговая проверка сценариев.
