# Freight board prototype

Кликабельный прототип биржи грузоперевозок в формате доски объявлений. Это песочница для проверки сущностей, правил и сценариев из [docs/TZ.md](docs/TZ.md). Бэкенда нет: данные хранятся в памяти и сохраняются в `localStorage`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты (Vitest)
npm run build      # проверка типов и production-сборка
npm run build:preview  # один самодостаточный файл dist/preview.html для показа без сервера
```

Без локального запуска прототип можно открыть по ссылке на опубликованное превью (её даёт сессия Claude после каждого этапа).

## Инструменты для сценариев

Все инструменты — в серой полосе «Test tools» под верхней панелью.

- **Войти как.** Выпадающий список или страница «Log in as»: любая компания из сида или модератор в один клик. В колонке «Seed profile» описано, какой сценарий представляет компания. Переключение считается входом компании.
- **Управление временем.** Текущая (симулированная) дата и кнопки «+1 day», «+1 week», «+6 months». Старт — 5 Oct 2026, 09:00 UTC. При сдвиге пересчитываются рейтинги (стаж, возраст отзывов и компании); изменения пишутся в лог с причиной «Daily recalculation». Объявления, у которых истёк срок жизни, получают статус «expired» и пропадают из поиска; владельцу приходит уведомление.
- **Тестовый баланс.** Страница «Balance»: кнопки «+ €10 / €50 / €100» (через адаптер платежей-заглушку), бесплатные контакты месяца, история проводок. Баланс и бесплатные контакты текущей компании также видны справа в верхней панели.
- **Лог событий.** Страница «Event log»: каждое открытие контакта, оплата, пополнение, вход, сдвиг времени и изменение рейтинга — со временем и причиной. Для изменений рейтинга показаны балл до и после и изменившиеся компоненты. Фильтры по типу события и компании.
- **Уведомления.** Страница «Notifications» со счётчиком непрочитанных: напоминания об истечении объявлений и уведомления об истечении. Подписки и возвраты добавятся на следующих этапах.
- **Сбросить данные.** Кнопка «Reset data» (с подтверждением) возвращает исходный сид. Сид детерминированный: после сброса состояние всегда одинаковое.

## Структура

```
src/
  domain/       типы, config, чистые правила и команды (без React)
  adapters/     реестр компаний, платежи, почта: интерфейсы и заглушки
  store/        хранилище, localStorage, сброс
  seed/         детерминированные сид-данные
  ui/           React: страницы, компоненты, тексты (ui/i18n/en.ts)
docs/           ТЗ, план, решения, роадмап
```

Решения и допущения описаны в [docs/DECISIONS.md](docs/DECISIONS.md), утверждённый план — в [docs/PLAN.md](docs/PLAN.md), оставшиеся этапы с критериями готовности — в [docs/ROADMAP.md](docs/ROADMAP.md). Правила работы с репозиторием для следующих сессий — в [CLAUDE.md](CLAUDE.md).

## Реализованные сценарии

Числа в шагах — для чистого сида (кнопка «Reset data»).

- Переключение между компаниями («войти как»), сохранение состояния между перезагрузками, сброс данных.
- **Перевозчик находит груз и открывает контакт.** Войти как Danube Haulage (перевозчик, 3 бесплатных контакта, 25 €) → Search → вкладка Cargo → фильтр From = Warsaw → открыть объявление. Рядом с кнопкой виден балл, отметка «Verified» или флаг, число отзывов. Нажатие на балл раскрывает компоненты. Первые 3 открытия бесплатны, четвёртое списывает 5 € с баланса. Повторно контакт этой компании бесплатен на любом её объявлении (у компаний, с которыми Danube уже работал по сид-данным, контакт открыт сразу).
- **Поиск с фильтрами.** Search → фильтры: откуда и куда с радиусом в км (From = Warsaw, ± 150 — добавятся грузы из Łódź), дата или диапазон дат, вес и объём «от — до», тип кузова, способ загрузки, минимальный рейтинг, «Only with reviews (3+)», «Only without red flags» (убирает Ghost Lines). Минимальный рейтинг не отсекает новичков без рейтинга: при минимуме 90 в выдаче остаются, например, Euro Cargo Partners и QuickRate Logistics с меткой «New member»; «Only with reviews» убирает их. Сортировка: по дате загрузки, ставке за км, рейтингу, свежести; приоритетные объявления всегда первыми. Если ничего не найдено — пустое состояние с подсказкой.
- **Размещение объявления.** Войти как Silesia Steel → «Post a listing». Обязательные поля отмечены «*»; при пустой отправке поля подсвечиваются. Грузовладелец размещает только грузы, перевозчик — только машины, экспедитор — и то и другое. Маршрут можно сохранить как шаблон и потом начать из него новую форму.
- **Открытое объявление и приоритет.** «My listings» → «Make open · €10» и «Priority placement · €15»: баланс уменьшается на 25 €, объявление первое в выдаче с меткой «Priority». Войти как Nordic Reefer (у него нет открытых контактов) → карточка: «Show contact», контакт бесплатный, бесплатные контакты не тратятся.
- **Истечение и продление.** Разместить груз с загрузкой завтра → «+1 day» дважды → в «Notifications» напоминание «expires on…» → ещё «+1 day» → уведомление об истечении, объявление пропало из поиска, в «My listings» на вкладке «Removed and expired» → «Extend» (можно указать новую дату загрузки) → снова в поиске; приоритет не перенёсся, «Open» сохранился.
- **Снятие с причиной.** «My listings» → «Remove» → одна из трёх причин. Причина видна в списке и в «Event log» и остаётся метрикой: на рейтинг не влияет (ТЗ).
- **Контакты закончились, денег нет.** Войти как Moravia Trans (3 из 3 бесплатных использованы, 0 €) → открыть груз компании, с которой Moravia ещё не работала: кнопка неактивна, объяснено почему → «Top up balance» → «+ €10» → вернуться на карточку → контакт открывается за 5 €, баланс 5 €. В «Event log» видны пополнение, оплата и открытие контакта.
- **Сдвиг времени и пересчёт рейтинга.** «+6 months» → «Event log» → тип «Rating changed»: у компаний изменился балл с причиной «Daily recalculation (182 days)», видны изменившиеся компоненты. Бесплатные контакты обновились (новый месяц), объявления истекли — в поиске пустое состояние.
- **Красный флаг.** Объявление Ghost Lines UAB (ликвидирована): предупреждение у кнопки, открытие требует повторного подтверждения.
- **Профиль компании с обоснованием балла.** Название компании в выдаче, в карточке («Company profile») или на странице «Log in as» ведёт в профиль: балл, отметки и флаги с пояснением, четыре компонента с номинальным и фактическим весом и вкладом в балл, разложение каждого компонента на слагаемые и история его изменений, отзывы (вес каждого и причины снижения, «No deal: contact rated» для отзывов без сделки), претензии со статусами и весом, данные реестра (возраст и отчётность — «shown for information, not scored»). Примеры: Danube Haulage — две свежие неподтверждённые претензии по −25, «Claims» = 50; Fast Profit Freight — одна претензия старше 30 дней «no longer counts»; Lowland Cargo — реестр не сообщает статус, «Official check» = 100 («does not lower the score»); Vistula Logistics — «Activity»: стаж и 11 контактов, по которым пришли отзывы.
- **Отзыв — обе стороны контакта, «перевозка состоялась?».** Войти как Nordic Reefer → профиль Rhein Spedition: вместо формы — «Only the sides of a contact can rate each other…». Открыть контакт на любом грузе Rhein → «Leave a review or a claim» → «Did the transport take place? Yes» → 2★ → балл Rhein 95 → 94 (автор — новичок, вес отзыва небольшой). Повторный отзыв недоступен до 3 Jan 2027; после «+6 months» снова доступен. Войти как Rhein → профиль Nordic Reefer: Rhein, чей контакт открыли, тоже может оценить Nordic; при ответе «No» подсказка «rate only the contact… not agreeing on the price is not a reason for a low mark», отзыв помечен «No deal: contact rated». Rhein → «Reply» под отзывом о себе (один раз).
- **Претензия.** Там же (Nordic Reefer → Rhein) «File a claim» → Rhein 94 → 92: претензия весит как отзыв новичка (вес 0,4, −9,9 балла в компоненте «Claims»). Rhein получает уведомление и может ответить («Answer the claim»). Неподтверждённая претензия перестаёт влиять через 30 дней; модератор может её подтвердить («Moderation» → «Claims» → «Confirm claim») — тогда она действует до урегулирования. «Mark as settled» (заявитель или модератор) → балл возвращается.
- **Жалоба и ответ компании.** Войти как Nordic Reefer, открыть контакт груза Rhein → в карточке «Report this listing»: «Listing is outdated» (всем), «Contact does not answer» и «Contact data is wrong» (после открытия контакта). Rhein получает уведомление, в «My listings» видит жалобу и отвечает («Answer») до решения. Модератор («Moderation» → «Complaints») видит ответ компании, долю жалоб и что вернётся при подтверждении.
- **Возврат за контакт.** «Contact data is wrong» (номер не существует) — после подтверждения модератором деньги или бесплатный контакт возвращаются сразу. «Contact does not answer» от одной компании возврата не даёт («no refund yet: 1.0 of 2 independent confirmed reports needed»); когда такую же жалобу на ту же компанию подтверждают по второй независимой компании, возврат получают обе. Компании с общим устройством считаются одной. Не больше 3 возвратов на аккаунт за 30 дней; у заявителя с высокой долей возвратов жалобы весят 0,5.
- **Скрытие объявлений по доле жалоб.** Объявления скрываются, только если подтверждённые жалобы составляют ≥ 20 % открытых контактов компании за 30 дней и их не меньше 3 (например, три жалобы «Listing is outdated» на Polska Agro от трёх компаний, подтверждённые модератором). Владелец получает уведомление → «My listings» → «Contact data is up to date» → объявления снова в поиске.
- **Оспаривание.** Кнопка «Dispute» — у событий рейтинга в «Changes» компонента (для своей компании), у своих флагов в профиле, у жалоб на свои объявления в «My listings», у претензий против себя в профиле. До решения рядом стоит «Disputed: waiting for the moderator». Модератор → «Moderation» → «Disputes»: «Accept» снимает флаг или отклоняет жалобу/претензию, «Reject» оставляет как есть; компания получает уведомление.
- **Несовпадение с реестром.** Профиль Euro Cargo Partners: жёлтый «Clarify your data» до 14 Oct 2026. Войти как Euro Cargo → кнопка «Use the registry name…» → флаг закрыт, «Verified». Без исправления «+1 week» дважды → флаг становится красным «Data not confirmed», компании приходит уведомление.
- **Неактивная компания.** Riga Container (последний вход ~5,5 месяца назад). Под любой другой компанией (вход под Riga обновил бы дату входа): «+1 week» → Riga получает предупреждение «will be hidden from search on 23 Oct 2026»; ещё «+1 week» дважды → Riga скрыта из поиска, рейтинг сохранён. Войти как Riga → в «Notifications» предупреждение и уведомление о скрытии, сверху баннер «Your company is hidden…» → «Confirm contacts and show my company» → снова в поиске, без повторной проверки.
- **Новый участник.** Объявление Nordic Reefer OÜ (вкладка Trucks): нейтральная метка «New member», балл считается по проверке и претензиям, отзывы и активность помечены «no data yet».
- **Общее устройство — без флага.** QuickRate Trans и QuickRate Logistics работают с одного устройства и оценили друг друга: флага нет, их взаимные отзывы весят меньше («shared device, mutual ×0.3»).
- **Замкнутое кольцо и вес отзыва вместо наказания.** Профиль Northline Freight (кольцо c19–c21: три новые компании, оценившие только друг друга на 5★): у каждого отзыва вес ≈ 0,12 («author with little history», «closed group»), компонент «Reviews» = 60, а не 100. Модератор → «Flags» → «Run now» (или «+1 day»): кольцо получает «Under review», отзывы внутри кольца получают вес 0, «Reviews» падает до нейтральных 50 (флаг не может повысить балл); отзывы участников кольца о компаниях вне кольца учитываются. «Confirm manipulation» → красный «Blocked», отзывы внутри кольца аннулируются. У честных партнёров со взаимными отзывами вес полный: Vistula Logistics и Baltic Freight оценили друг друга на 5★, отзыв Vistula весит 1,00, отзыв Baltic — 0,50 только из-за возраста; во всём сиде 26 взаимных пар, ни одна не понижена за замкнутость.
- **Скрытые объявления.** Объявления заблокированной Fast Profit Freight в выдаче не показываются.
