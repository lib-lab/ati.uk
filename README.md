# Freight board prototype

Кликабельный прототип биржи грузоперевозок в формате доски объявлений. Это песочница для проверки сущностей, правил и сценариев из [docs/TZ.md](docs/TZ.md). Бэкенда нет: данные хранятся в памяти и сохраняются в `localStorage`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты (Vitest)
npm run build      # проверка типов и production-сборка
npm run build:preview  # один самодостаточный файл dist/preview.html для показа без сервера
```

Без локального запуска прототип можно открыть по ссылке на опубликованное превью (её даёт сессия Claude после каждого этапа).

## Инструменты для сценариев

Все инструменты — в серой полосе «Test tools» под верхней панелью. На узком экране (< 640 px) полоса свёрнута в одну строку с текущей компанией и датой; нажатие разворачивает её.

- **Войти как.** Выпадающий список или страница «Log in as»: любая компания из сида или модератор в один клик. В колонке «Seed profile» описано, какой сценарий представляет компания. Новую компанию можно зарегистрировать ссылкой «Register a company» на странице «Log in as». Компании c22–c33 — фоновые клиенты Moravia Trans и Euro Cargo Partners: без активных объявлений, нужны для сценария «компания с историей». Переключение считается входом компании.
- **Управление временем.** Текущая (симулированная) дата и кнопки «+1 hour», «+1 day», «+1 week», «+6 months». Старт — 5 Oct 2026, 09:00 UTC. При сдвиге пересчитываются рейтинги (стаж, возраст отзывов и компании); изменения пишутся в лог с причиной «Daily recalculation». Объявления, у которых истёк срок жизни, получают статус «expired» и пропадают из поиска; владельцу приходит уведомление.
- **Тестовый баланс.** Страница «Balance»: кнопки «+ €10 / €50 / €100» (через адаптер платежей-заглушку), бесплатные контакты месяца, пакет контактов (покупка, остаток, срок), история проводок. Баланс и бесплатные контакты текущей компании также видны справа в верхней панели.
- **Лог событий.** Страница «Event log»: каждое открытие контакта, оплата, пополнение, вход, сдвиг времени и изменение рейтинга — со временем и причиной. Для изменений рейтинга показаны балл до и после и изменившиеся компоненты. Фильтры по типу события и компании.
- **Подписки.** На странице поиска «Save as subscription» (рядом выбор «Instantly» / «Hourly digest»), список — «Subscriptions» в верхней панели. Письма адресованы тестовому ящику 90569oc62@mozmail.com, но уходят в почтовую заглушку (реально не отправляются); в «Event log» — события «E-mail sent» с адресом.
- **Уведомления.** Страница «Notifications» со счётчиком непрочитанных и ссылками на объявления: напоминания и уведомления об истечении объявлений, подписки, жалобы, претензии, возвраты, правки открытых объявлений, замедление открытий.
- **Simulate a bot.** Текущая компания пытается открыть до 6 контактов разных компаний подряд в обход карточек и без проверки «я человек», как программа-сборщик. Результат показан рядом с кнопкой. Деньги и бесплатные контакты списываются как обычно.
- **Сбросить данные.** Кнопка «Reset data» (с подтверждением) возвращает исходный сид. Сид детерминированный: после сброса состояние всегда одинаковое.

## Обязательные сценарии

Десять сценариев из ROADMAP. Все проходят по шагам ниже на чистом сиде («Reset data»); проверено в браузере на ширине 1280 и 390 px.

1. Перевозчик находит груз фильтрами, видит рейтинг, открывает контакт, баланс списывается, повторно бесплатно — «Перевозчик находит груз и открывает контакт», «Поиск с фильтрами».
2. Бесплатные контакты закончились — понятное состояние и предложение пополнить баланс — «Контакты закончились, денег нет».
3. Грузовладелец делает объявление открытым и включает приоритетный показ — «Открытое объявление и приоритет» (например, под Silesia Steel).
4. Отзыв только после открытия контакта, не чаще правила из ТЗ — «Отзыв — обе стороны контакта, „перевозка состоялась?“».
5. Жалоба «контакт не отвечает» подтверждена модератором — оплата возвращается, жалоба учитывается — «Возврат за контакт»: Nordic Reefer и Fresh Start Transport открывают контакт Rhein Spedition и жалуются «Contact does not answer», модератор подтверждает обе — возврат получают обе компании.
6. Красный флаг: предупреждение у кнопки контакта — «Красный флаг».
7. Новый участник без отзывов: нейтральная метка, балл по доступным компонентам — «Новый участник».
8. Подписка на поиск: новое объявление появляется в уведомлениях — «Подписка „сразу“».
9. Объявление истекает после сдвига времени, владелец продлевает его — «Истечение и продление».
10. Простая страница модератора: жалобы, претензии, флаги — «Moderation» под модератором.

## Реализованные сценарии

Числа в шагах — для чистого сида (кнопка «Reset data»).

- Переключение между компаниями («войти как»), сохранение состояния между перезагрузками, сброс данных.
- **Перевозчик находит груз и открывает контакт.** Войти как Danube Haulage (перевозчик, 3 бесплатных контакта, 25 €) → Search → вкладка Cargo → фильтр From = Warsaw → открыть объявление. Рядом с кнопкой виден балл, отметка «Verified» или флаг, число отзывов. Нажатие на балл раскрывает компоненты. Первые 3 открытия бесплатны, четвёртое списывает 5 € с баланса. Повторно контакт этой компании бесплатен на любом её объявлении (у компаний, с которыми Danube уже работал по сид-данным, контакт открыт сразу).
- **Поиск с фильтрами.** Search → фильтры: откуда и куда с радиусом в км (From = Warsaw, ± 150 — добавятся грузы из Łódź), дата или диапазон дат, вес и объём «от — до», тип кузова, способ загрузки, минимальный рейтинг, «Only with reviews (3+)», «Only without red flags» (убирает Ghost Lines). Минимальный рейтинг не отсекает новичков без рейтинга: при минимуме 90 в выдаче остаются, например, Euro Cargo Partners и QuickRate Logistics с меткой «New member»; «Only with reviews» убирает их. Сортировка: по дате загрузки, ставке за км, рейтингу, свежести; приоритетные объявления всегда первыми. Если ничего не найдено — пустое состояние с подсказкой.
- **Размещение объявления.** Войти как Silesia Steel → «Post a listing». Обязательные поля отмечены «*»; при пустой отправке поля подсвечиваются. Грузовладелец размещает только грузы, перевозчик — только машины, экспедитор — и то и другое. Маршрут можно сохранить как шаблон и потом начать из него новую форму.
- **Открытое объявление и приоритет.** «My listings» → «Make open · €10» и «Priority placement · €15»: баланс уменьшается на 25 €, объявление первое в выдаче с меткой «Priority». Войти как Nordic Reefer (у него нет открытых контактов) → карточка: «Show contact», контакт бесплатный, бесплатные контакты не тратятся.
- **Истечение и продление.** Разместить груз с загрузкой завтра → «+1 day» дважды → в «Notifications» напоминание «expires on…» → ещё «+1 day» → уведомление об истечении, объявление пропало из поиска, в «My listings» на вкладке «Removed and expired» → «Extend» (можно указать новую дату загрузки) → снова в поиске; приоритет не перенёсся, «Open» сохранился.
- **Снятие с причиной.** «My listings» → «Remove» → одна из трёх причин. Причина видна в списке и в «Event log» и остаётся метрикой: на рейтинг не влияет (ТЗ).
- **Контакты закончились, денег нет.** Войти как Moravia Trans (3 из 3 бесплатных использованы, 0 €) → открыть груз компании, с которой Moravia ещё не работала: кнопка неактивна, объяснено почему → «Top up balance» → «+ €10» → вернуться на карточку → контакт открывается за 5 €, баланс 5 €. В «Event log» видны пополнение, оплата и открытие контакта.
- **Сдвиг времени и пересчёт рейтинга.** «+6 months» → «Event log» → тип «Rating changed»: у компаний изменился балл с причиной «Daily recalculation (182 days)», видны изменившиеся компоненты. Бесплатные контакты обновились (новый месяц), объявления истекли — в поиске пустое состояние.
- **Красный флаг.** Объявление Ghost Lines UAB (ликвидирована): предупреждение у кнопки, открытие требует повторного подтверждения.
- **Профиль компании с обоснованием балла.** Название компании в выдаче, в карточке («Company profile») или на странице «Log in as» ведёт в профиль: балл, отметки и флаги с пояснением, четыре компонента с номинальным и фактическим весом и вкладом в балл, разложение каждого компонента на слагаемые и история его изменений, отзывы (вес каждого и причины снижения, «No deal: contact rated» для отзывов без сделки), претензии со статусами и весом, данные реестра (возраст и отчётность — «shown for information, not scored»). Примеры: Danube Haulage — две свежие неподтверждённые претензии по −25, «Claims» = 50; Fast Profit Freight — одна претензия старше 30 дней «no longer counts»; Lowland Cargo — реестр не сообщает статус, «Official check» = 100 («does not lower the score»); Vistula Logistics — «Activity»: стаж и 11 контактов, по которым пришли отзывы.
- **Отзыв — обе стороны контакта, «перевозка состоялась?».** Войти как Nordic Reefer → профиль Rhein Spedition: вместо формы — «Only the sides of a contact can rate each other…». Открыть контакт на любом грузе Rhein → «Leave a review or a claim» → «Did the transport take place? Yes» → 2★ → балл Rhein 95 → 94 (автор — новичок, вес отзыва небольшой). Повторный отзыв недоступен до 3 Jan 2027; после «+6 months» снова доступен. Войти как Rhein → профиль Nordic Reefer: Rhein, чей контакт открыли, тоже может оценить Nordic; при ответе «No» подсказка «rate only the contact… not agreeing on the price is not a reason for a low mark», отзыв помечен «No deal: contact rated». Rhein → «Reply» под отзывом о себе (один раз).
- **Претензия.** Там же (Nordic Reefer → Rhein) «File a claim» → Rhein 94 → 92: претензия весит как отзыв новичка (вес 0,4, −9,9 балла в компоненте «Claims»). Rhein получает уведомление и может ответить («Answer the claim»). Неподтверждённая претензия перестаёт влиять через 30 дней; модератор может её подтвердить («Moderation» → «Claims» → «Confirm claim») — тогда она действует до урегулирования. «Mark as settled» (заявитель или модератор) → балл возвращается.
- **Жалоба и ответ компании.** Войти как Nordic Reefer, открыть контакт груза Rhein → в карточке «Report this listing»: «Listing is outdated» (всем), «Contact does not answer» и «Contact data is wrong» (после открытия контакта). Rhein получает уведомление, в «My listings» видит жалобу и отвечает («Answer») до решения. Модератор («Moderation» → «Complaints») видит ответ компании, долю жалоб и что вернётся при подтверждении.
- **Возврат за контакт.** «Contact data is wrong» (номер не существует) — после подтверждения модератором деньги или бесплатный контакт возвращаются сразу. «Contact does not answer» от одной компании возврата не даёт («no refund yet: 1.0 of 2 independent confirmed reports needed»); когда такую же жалобу на ту же компанию подтверждают по второй независимой компании, возврат получают обе. Компании с общим устройством считаются одной. Не больше 3 возвратов на аккаунт за 30 дней; у заявителя с высокой долей возвратов жалобы весят 0,5.
- **Скрытие объявлений по доле жалоб.** Объявления скрываются, только если подтверждённые жалобы составляют ≥ 20 % открытых контактов компании за 30 дней и их не меньше 3 (например, три жалобы «Listing is outdated» на Polska Agro от трёх компаний, подтверждённые модератором). Владелец получает уведомление → «My listings» → «Contact data is up to date» → объявления снова в поиске.
- **Оспаривание.** Кнопка «Dispute» — у событий рейтинга в «Changes» компонента (для своей компании), у своих флагов в профиле, у жалоб на свои объявления в «My listings», у претензий против себя в профиле. До решения рядом стоит «Disputed: waiting for the moderator». Модератор → «Moderation» → «Disputes»: «Accept» снимает флаг или отклоняет жалобу/претензию, «Reject» оставляет как есть; компания получает уведомление.
- **Несовпадение с реестром.** Профиль Euro Cargo Partners: жёлтый «Clarify your data» до 14 Oct 2026. Войти как Euro Cargo → кнопка «Use the registry name…» → флаг закрыт, «Verified». Без исправления «+1 week» дважды → флаг становится красным «Data not confirmed», компании приходит уведомление.
- **Неактивная компания.** Riga Container (последний вход ~5,5 месяца назад). Под любой другой компанией (вход под Riga обновил бы дату входа): «+1 week» → Riga получает предупреждение «will be hidden from search on 23 Oct 2026»; ещё «+1 week» дважды → Riga скрыта из поиска, рейтинг сохранён. Войти как Riga → в «Notifications» предупреждение и уведомление о скрытии, сверху баннер «Your company is hidden…» → «Confirm contacts and show my company» → снова в поиске, без повторной проверки.
- **Новый участник.** Объявление Nordic Reefer OÜ (вкладка Trucks): нейтральная метка «New member», балл считается по проверке и претензиям, отзывы и активность помечены «no data yet».
- **Общее устройство — без флага.** QuickRate Trans и QuickRate Logistics работают с одного устройства и оценили друг друга: флага нет, их взаимные отзывы весят меньше («shared device, mutual ×0.3»).
- **Замкнутое кольцо и вес отзыва вместо наказания.** Профиль Northline Freight (кольцо c19–c21: три новые компании, оценившие только друг друга на 5★): у каждого отзыва вес ≈ 0,12 («author with little history», «closed group»), компонент «Reviews» = 60, а не 100. Модератор → «Flags» → «Run now» (или «+1 day»): кольцо получает «Under review», отзывы внутри кольца получают вес 0, «Reviews» падает до нейтральных 50 (флаг не может повысить балл); отзывы участников кольца о компаниях вне кольца учитываются. «Confirm manipulation» → красный «Blocked», отзывы внутри кольца аннулируются. У честных партнёров со взаимными отзывами вес полный: Vistula Logistics и Baltic Freight оценили друг друга на 5★, отзыв Vistula весит 1,00, отзыв Baltic — 0,50 только из-за возраста; во всём сиде 26 взаимных пар, ни одна не понижена за замкнутость.
- **Скрытые объявления.** Объявления заблокированной Fast Profit Freight в выдаче не показываются.
- **Правка объявления, история и уведомления.** Войти как Nordic Reefer → Search → Cargo → груз Rhein Spedition (Frankfurt → Warsaw) → «Open contact» (бесплатно). Войти как Rhein → карточка → «Edit» (или «My listings» → «Edit») → изменить вес и комментарий → «Save changes». На карточке в «Change history» запись с пометкой «Key field»: «Weight, t: 13.6 t → 15.6 t», «Comment: …». Войти как Nordic Reefer → «Notifications»: «Listing … that you opened was changed: weight, t; comment». Если менялся только комментарий, пометки «Key field» нет и права на возврат тоже.
- **Возврат после ключевой правки.** Продолжение предыдущего: Nordic Reefer → карточка этого груза → «The route, dates, body type, weight or rate changed within 24 hours…» → «Get the payment back»: бесплатных контактов снова 3/3 (при оплате с баланса вернулись бы 5 €). После «+1 day» новая правка права на возврат уже не даёт.
- **Контакт не виден до открытия.** В выдаче и на карточке до открытия нет ни имени, ни телефона: данные карточки приходят без контактного лица, контакт отдаёт только доменная проверка доступа. Если доступ к компании уже открыт через другое её объявление, на новой карточке кнопка «Show contact»: бесплатно, но раскрытие записывается, чтобы компания получала уведомления о правках и этого объявления.
- **Сбор контактов: замедление, затем блокировка.** Войти как Vistula Logistics → «Simulate a bot»: «Bot: 5 opened» — после 5 открытий без карточки компания замедлена, приходит уведомление. Карточка любой компании, с которой Vistula ещё не работала: «I am a human, not a program» → контакт открывается; без отметки кнопка неактивна, не больше 5 открытий в час; «+1 hour» — можно открыть ещё 5. «Simulate a bot» ещё раз: попытки без проверки продолжаются → «Opening contacts is blocked». Модератор → «Moderation» → «Contact collection»: причины и «Unblock».
- **Суточный лимит.** «Account» → «N of 50 new contacts today». Moravia Trans или Euro Cargo Partners (больше 3 месяцев на площадке и 21 открытый контакт при пороге 20) → «Raise to 150» → лимит 150 без проверки. У новых компаний кнопка неактивна, объяснено, чего не хватает.
- **Согласие на показ данных.** Войти как Rhein → «Account» → «Withdraw consent» у Jonas Becker. Войти как Nordic Reefer (контакт открыт) → карточка груза Rhein: «The contact person withdrew consent…», имени и телефона нет. Rhein → «Give consent» → контакт снова виден. Текст согласия — заглушка («Consent text»).
- **Выгрузка данных.** «Account» → «Request my data» → ввести название компании (регистр не важен; пока название не совпало, кнопка неактивна) → «Prepare the data»: JSON со всеми данными компании в поле с кнопкой «Copy» (и скачивание файла, если хост разрешает). В «Event log» — «Data downloaded».
- **Удаление аккаунта.** «Account» → «Delete account» → ввести название компании (например, «rhein spedition gmbh»; «Rhein» не подходит) → «Delete»: контактные лица удалены, активные объявления сняты, вход под компанией невозможен (текущий пользователь переключается на модератора). Профиль: «Account deleted on …»; отзывы, претензии и история рейтинга сохранены и привязаны к компании без имени человека.
- **Срок хранения журнала открытий.** Записи журнала открытий старше 12 месяцев обезличиваются при сдвиге времени (в сиде часть записей уже обезличена). «+6 months» дважды → в «Event log» «N contact openings older than 12 months anonymised».
- **Имена людей в отзывах.** В формах отзыва и претензии предупреждение: имена и телефоны людей не писать. Автоматической очистки нет. Удалить Rhein Spedition (см. «Удаление аккаунта») → модератор → профиль Vistula Logistics → у отзыва Rhein «Hide text (personal data request)» → «Requested by»: Rhein Spedition GmbH → «Hide text». Вместо текста — «Text hidden on … at the request of a former user», звёзды и балл Vistula (95) не изменились; в «Event log» — «Review text hidden». Пока удалённых аккаунтов нет, действие недоступно.
- **Подписка «сразу».** Войти как Baltic Freight (перевозчик) → Search → Cargo → From = Warsaw, Body type = Tent → «Instantly» → «Save as subscription». Повторное сохранение тех же фильтров: «A subscription with these filters already exists». Войти как Polska Agro → разместить груз Warsaw → Berlin, Tent. Войти как Baltic Freight → «Notifications»: «New listing for your subscription: Warsaw → Berlin (…)» со ссылкой «Open …». Груз Kraków → Berlin или Warsaw → Berlin с кузовом Reefer уведомления не даёт; своё объявление тоже.
- **Подписка дайджестом.** Войти как Moravia Trans → те же фильтры → «Hourly digest» → сохранить. Polska Agro размещает два подходящих груза. У Moravia уведомлений нет, в «Subscriptions» — «2 waiting for the next digest». «+1 hour» → одно уведомление «2 new listings for your subscriptions: …» с двумя ссылками.
- **Правка и подписка.** Груз из Prague не подходит под подписку «From = Warsaw»; владелец меняет город загрузки на Warsaw («Edit») → подписчику приходит уведомление. Повторные правки этого объявления больше уведомлений не дают.
- **Письма и управление подписками.** «Event log» → тип «E-mail sent»: письмо на каждое уведомление подписки. «Subscriptions»: фильтры текстом, сколько объявлений уже пришло, смена частоты, «Open in search» (поиск открывается с сохранёнными фильтрами), «Delete» с подтверждением.
- **Регистрация и проверка по реестру.** «Log in as» → «Register a company». Тестовый реестр решает по последней цифре номера: обычный номер (например, PL NIP 7011234562) → «Verified», новая компания сразу становится текущей; …9 → красный «Not recommended»; …8 → «Clarify your data: the registry name is …» с датой (через 14 дней флаг станет красным, исправить — кнопкой в профиле); …0 → «not found», тот же жёлтый флаг. Без отметки согласия — «Consent is required…»; у созданного контактного лица в «Account» видна дата согласия. Номер Vistula Logistics (PL, 525-123-45-61 в любом написании) → «This number is already registered in PL: one company — one account».
- **Смена роли.** Зарегистрированная компания-перевозчик → «Post a listing»: только машины. Свой профиль → «Role» → Shipper → «Change role» → «Post a listing»: только грузы. В «Event log» — «Role of … changed».
- **Ежедневная сверка с реестром.** При каждом «+1 day» реестр сверяется со всеми неудалёнными компаниями: сид стабилен (новых флагов реестра нет); если реестр начнёт сообщать ликвидацию или другое название, флаг появится, а когда данные снова совпадут — закроется (проверено тестами, в интерфейсе заглушка реестра не меняется).
- **Пакет контактов.** Войти как Moravia Trans (0 €, бесплатные контакты месяца израсходованы) → «Balance» → «Buy a package · €70» → «Not enough balance» → «+ €100» → «Buy a package»: баланс 30 €, в верхней панели «Package 20/20 until 4 Nov 2026»; второй пакет купить нельзя, пока этот действует. Карточка груза компании, с которой Moravia ещё не работала: «Open contact · from package», «19 of 20 left after this» → открыть: пакет 19/20, баланс по-прежнему 30 €. «+1 week» × 5 → пакет истёк и пропал из панели; в новом месяце сначала снова 3 бесплатных контакта, потом открытие списывает баланс.
- **Возврат в пакет.** Контакт, открытый из пакета, при подтверждённой жалобе «Contact data is wrong» или ключевой правке объявления в течение 24 часов возвращается в пакет (остаток +1), пока пакет действует. Модератор видит «the contact goes back to the package»; для истёкшего пакета — «no refund: the package has expired».

## Известные ограничения

- **Нет сервера.** Всё состояние живёт в браузере (localStorage) у одного пользователя; «войти как» — без пароля. Правила доступа (контакт только после открытия, лимиты, автосбор) проверяются в доменном слое, но данные контактов технически лежат в состоянии браузера: в настоящей системе ту же проверку делает сервер.
- **Время симулированное** и стоит между нажатиями. Самый мелкий шаг — «+1 hour»; признаки «за минуты» (всплеск открытий) считаются по одинаковым отметкам времени.
- **Внешние системы — заглушки.** Реестр решает по последней цифре номера; сверка с реестром синхронна только у заглушки. Платежи — тестовый режим. Письма адресованы тестовому ящику 90569oc62@mozmail.com, но не отправляются; второго канала (push, мессенджер) нет. Проверка «я человек» — чекбокс вместо капчи.
- **Юридические тексты** (согласие, политика) — заглушки. Скачать выгрузку данных файлом в превью нельзя: просмотрщик запрещает загрузки, данные берутся из текстового поля.
- **Масштаб.** Рейтинги и детектор колец пересчитываются на лету по всем данным — для сида это мгновенно, для тысяч компаний понадобится кэш. Лог событий растёт без ограничений, а localStorage вмещает несколько мегабайт: после долгой работы может понадобиться «Reset data».
- **Мобильная версия базовая:** выдача карточками, свёрнутые инструменты и фильтры, без горизонтальной прокрутки; навигация переносится на несколько строк.
- **Одна валюта (EUR)**, расстояния — по прямой × 1,2. Решения модератора не подписываются конкретным модератором, сроки ответа не моделируются.
- **Проверено** в Chromium (Playwright) на ширине 1280 и 390 px; другие браузеры не проверялись.
